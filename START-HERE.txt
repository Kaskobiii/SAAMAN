SAAMAN 1.3.33
Unload the old DLL and load SAAMAN.dll in ALL connected EuroScope instances,
including the sequencer and proxies. Keep SAAMAN above TopSky in the plug-in list.

Shared vatIRIS mode is the default. Backend: https://backend.vatiris.se
No separate vatIRIS login or controller key is needed. No backend update needed.
Eligible sequencers: ESOS/ESAA CTR, ESSA APP, ESSA_FMP (including handovers).
ESMM does not autoconnect; manual shared connection remains available.
Priming to ESOS/ESAA/ESSA enables automatic connection without a plugin reload.

Set both ESSA ARR and DEP in the sequencer's EuroScope. Sync EuroScope updates
AMAN's shared plan; it does not change other controllers' EuroScope settings
or the runway/STAR already assigned to each flight.

Read docs/RELEASE-NOTES-1.3.33.md for examples and docs/user-guide.html for use.
