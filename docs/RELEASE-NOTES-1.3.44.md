# SAAMAN 1.3.44

- Default ESSA arrival rate is now 38 aircraft per hour, using a 95-second landing interval.
- The arrival-rate slider moves in steps of one aircraft per hour. Increasing the slider increases the rate, making small changes around 38 easier to select.

Existing shared sessions retain their selected rate. Set 38 in the rate menu and press Apply to update an ongoing session.

790 model tests, the rendered slider checks, UI type checking and the Windows Release/native context checks passed.
